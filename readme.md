# Предсказание стоимости аренды жилья

**Полный цикл ML-проекта: от аналитического вывода линейной регрессии до сравнения собственных реализаций с `sklearn`, feature engineering и борьбы с переобучением.**

---

## 📖 О проекте

Проект представляет собой комплексное исследование задачи **регрессии** на реальных данных сервиса аренды жилья **RentHop** (Нью-Йорк, ~50 000 объявлений). В работе реализованы **линейные модели с нуля** (аналитическое решение, Batch GD, SGD, Mini-batch GD) и проведено их сравнение с промышленными реализациями из `scikit-learn`.

Помимо базовых моделей, в проекте реализованы:
- **Регуляризация L1/L2/ElasticNet** через проксимальный градиент (ISTA) и soft-thresholding;
- **Кастомные скейлеры** (`MinMaxScaler`, `StandardScaler`) с побитовым сравнением с `sklearn`;
- **Feature engineering** на основе списка удобств квартиры;
- **Анализ переобучения** на полиномиальных признаках 10-й степени;
- **Работа с «тяжёлыми хвостами»** распределения целевой переменной (Yeo-Johnson) и выбросами.

## 🧠 Ключевые технические решения

### 1. Аналитическое решение МНК
$$\mathbf{w}^* = (\mathbf{X}^\top \mathbf{X})^{-1} \mathbf{X}^\top \mathbf{y}$$

### 2. Ridge-регрессия (L2)
$$\mathbf{w}^*_{\text{ridge}} = (\mathbf{X}^\top \mathbf{X} + \lambda \mathbf{I})^{-1} \mathbf{X}^\top \mathbf{y}$$

### 3. Lasso (L1) через ISTA
$$w_j \leftarrow \text{sign}(w_j - \eta \nabla_j) \cdot \max\!\bigl(0,\ |w_j - \eta \nabla_j| - \eta \alpha\bigr)$$

### 4. ElasticNet
$$w_j \leftarrow \frac{1}{1 + \eta\alpha(1-\rho)} \cdot \text{soft\_threshold}\bigl(w_j - \eta\nabla_j,\ \eta\alpha\rho\bigr)$$

### 5. Детерминированный SGD
Фиксация `np.random.default_rng(random_state)` и использование `permutation()` для воспроизводимости порядка обхода выборки.

## 📊 Результаты

### Сравнение моделей на тестовой выборке (MAE ↓)

| Модель | MAE | RMSE | R² |
|--------|-----|------|-----|
| **Lasso_sklearn** (MinMax) | **690.4** | **993.5** | **0.573** |
| Ridge_sklearn (MinMax) | 691.1 | 993.6 | 0.573 |
| LinearRegression_sklearn | 691.1 | 993.6 | 0.573 |
| ElasticNet_sklearn | 744.7 | 1076.9 | 0.498 |
| Ridge_custom | 845.2 | 1150.3 | 0.428 |
| Lasso_custom | 691.0 | 993.5 | 0.573 |
| ElasticNet_custom | 690.5 | 994.6 | 0.572 |

> 💡 **Вывод:** кастомные реализации, обученные на стандартизированных признаках, воспроизводят результаты `sklearn` с точностью до долей процента. Наилучшее качество показала модель **Lasso** (L1-регуляризация отсеивает неинформативные признаки).

### Борьба с переобучением (полиномы 10-й степени)

| Модель | test_R² |
|--------|---------|
| LinearRegression | 0.9002 |
| **Ridge (best α)** | **0.90018** |
| **Lasso (best α)** | **0.90018** |
| **ElasticNet (best α)** | 0.90018 |

`GridSearchCV` подобрал `alpha=10` для Ridge и `alpha=0.001` для Lasso/ElasticNet — регуляризация **нивелировала переобучение** без потери качества.

### Работа с распределением целевой переменной

| Метод | MAE ↓ | RMSE ↓ | R² ↑ |
|-------|-------|--------|------|
| Без трансформации (Raw) | 4.92 | 6.47 | 0.836 |
| **Yeo-Johnson** | **4.48** | **5.77** | **0.869** |
| Δ (улучшение) | −0.44 | −0.70 | **+0.034** |

## 🏆 Итоги

1. **Лучшая модель** — `Lasso` со `StandardScaler`/`MinMaxScaler` (test R² ≈ 0.573, MAE ≈ 690 $).
2. **Наиболее стабильная** — `Ridge`: разница между train и test метриками минимальна.
3. **Кастомные реализации** практически идентичны `sklearn` при достаточном числе эпох обучения.
4. **Yeo-Johnson трансформация** целевой переменной даёт прирост R² на **+3.4 п.п.** — самый эффективный приём из дополнительного блока.
